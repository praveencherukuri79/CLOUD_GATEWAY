Clickable cURL Tests

Each command has a Run button that performs the equivalent request in the browser, plus a Copy button. 

curl -i -c cookies.txt -X POST http://localhost:8080/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=demoUser123&password=password"
curl -b cookies.txt -c cookies.txt http://localhost:8080/api/local/hello
curl -b cookies.txt -c cookies.txt http://localhost:8080/proxy/users/123
curl -b cookies.txt -c cookies.txt http://localhost:8080/proxy/orders/456
curl -b cookies.txt -c cookies.txt http://localhost:8080/custom-proxy/notifications/101
curl -b cookies.txt -c cookies.txt http://localhost:8080/custom-proxy/alerts/202

Expected Behavior

  • /api/local/hello returns a local controller response with the logged-in user.
  • /proxy/users/123 and /proxy/orders/456 are forwarded by the gateway.
  • /custom-proxy/notifications/101 and /custom-proxy/alerts/202 are forwarded by custom controller logic.
  • The BFF creates an internal bearer token before forwarding.
  • The browser only uses the BFF session cookie.
